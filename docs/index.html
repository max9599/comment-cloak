What it does

Read the code. Not the narration.

Copilot, Claude and Cursor narrate every step. CommentCloak folds that narration away using the editor's own fold regions — and brings it back with a single keystroke.

Smart filters

Hide obvious AI comments, keep meaningful ones.

Keep what matters

Preserve TODO, FIXME, eslint, JSDoc, @ts-ignore, etc.

Customize

Choose comment kinds, keep-list regexes and marker style.

Works across IDEs

WebStorm, IntelliJ IDEA, PyCharm, GoLand, Rider and more.

Safe & non-destructive

No file modifications. Purely a visual improvement.

How it works

Three steps to a quieter editor.

CommentCloak is not on the JetBrains Marketplace yet — install it from disk. Requires build 252 (2025.2) or newer.

1

Download the plugin

Grab the latest comment-cloak-<version>.zip from GitHub Releases.

2

Install from disk

Settings → Plugins → ⚙ → Install Plugin from Disk…, pick the zip, then restart the IDE when prompted.

3

Cloak the noise

Press Ctrl Alt / — ⌃ ⌥ / on macOS — or click a pill to bring one comment back.

  • Hover a pill to peek at the text it stands for, without unfolding anything.
  • Click to reveal a comment — it re-cloaks itself once your caret leaves it.
  • Status bar switch shows Comments: hidden / shown; click to flip.
  • Tune it in Settings → Editor → CommentCloak.
